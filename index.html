Settings (local model)

A self-hosted OSRM keeps your start point off the public router (see selfhost/README.md). Geocoding, tree data and elevation still use public services.

If the local model can't be reached, a simple built-in parser handles the request instead.

    Open pieces: an open-weight model via Ollama, OpenStreetMap data (Overpass, Nominatim, OSM foot routing), Open-Meteo elevation (Copernicus DEM), Leaflet. Tree and park cover is a proxy for foliage and shade, not a live leaf-color reading.
